# cdhdt-sandbox

Infrastructure e-commerce publique, complète et reproductible, présentée comme
une fiction d'un environnement réel. Vitrine sur trois compétences : le
développement, l'intégration de flux entre progiciels, et la sécurité d'un
système exposé sur Internet.

**Aucun paiement n'est réel. Aucune donnée personnelle de tiers n'entre dans ce
système.**

## État

Phase 0, cadrage. Aucun code applicatif à ce jour.
